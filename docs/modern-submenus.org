#+TITLE: Modern native submenu cards

* Native design
The existing mutually exclusive GTK revealers now contain a rounded card,
a descriptive heading and a compact close icon with the accessible name
"Close panel". The icon falls back to a multiplication sign when the theme
does not provide window-close-symbolic. All seven mode buttons remain native
buttons; the selected mode receives the shared accent color on startup and
after every mode change. No calculation or keyboard dispatch is replaced.

History, Memory and Settings use spaced native controls and local 14px text.
Card headings use 16px text. Combo boxes have transparent outer nodes and
rounded inner buttons, avoiding the rectangular outer background that
remained visible when only the button was styled. History requests 320px
instead of 360px so the card padding and margins fit the 381px compact window.
Light and dark surfaces, borders, focus indicators and dropdown contents
use the shared palette. Calculation-status tooltips remain suppressed;
button help remains available.

* Native rendering probe
Run =tools/submenu-native-probe.ps1= after =tools/build.ps1=. It uses the
existing hidden/offscreen header snapshot path with
=NELISP_CALC_HEADER_PROBE=submenu=. The value =1= retains the original header
probe behavior. No new launcher environment variable is introduced.

Each of eight light/dark panel cases drives the real navigation command,
keeps automation alive until GTK has allocated the widget tree, and renders
both the complete native window and the actual revealer child. It writes
=header-native.png=, =panel-native.png= and allocation TSV receipts beneath
=target/submenu-native-<id>/=. The probe requires no backend process. Each
owned process has a five-second timeout and unconditional cleanup. It checks
compact geometry, card allocation, close target height, GTK/CSS diagnostics
and unchanged foreground ownership. It never captures the desktop or
activates a foreground window.

This improves the design feedback loop: one bounded invocation produces
eight allocated native panel images, versus zero panel-child images in the
previous header-only probe. Popup dropdown lists are styled but were not
physically opened or captured. Native maximize, drag and minimize remain
outside this nonactivating test.
